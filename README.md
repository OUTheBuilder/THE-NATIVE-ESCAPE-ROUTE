# OU Escape Route: build project

Web UI (`www/`) extracted from your APK, wrapped in Capacitor, plus the
self-closing social browser plugin (`plugin/`). `android/` is generated by the build.

## Option A: build online (no Android Studio)
1. Create a GitHub repo and push this folder.
2. Actions tab -> "Build APK" -> Run workflow (also runs on every push to main).
3. Download the `ou-escape-route-apk` artifact. Without secrets you get a
   debug APK, which installs on any device (enable "install unknown apps").

## Release signing (for a distributable APK)
    keytool -genkey -v -keystore release.jks -alias ou -keyalg RSA -keysize 2048 -validity 10000
    base64 -w0 release.jks     # paste output into secret KEYSTORE_BASE64
Repo secrets: KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD.
Back up release.jks safely: you need the same key for every future update.

## Option B: build locally
Needs Node 18+, JDK 17, Android SDK (ANDROID_HOME set).
    npm run build:debug
    # or, with the 4 KEYSTORE_* / KEY_* env vars set:
    npm run build:release
Output: dist/*.apk

## Using the social browser
Copy `web-src/socialBrowser.ts` into your web source and call
`openSocial(url, isPremium)`. Note: `www/` is minified build output, so to
wire that call in you need your original source (or edit the built JS).

## Notes
- Default Capacitor icon is used; to use your logo, add `@capacitor/assets`.
- This APK is signed with a new key, so users must uninstall the old
  version before installing it.
